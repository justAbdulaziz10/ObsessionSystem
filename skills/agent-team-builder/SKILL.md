# Agent Team Builder

Stay within assigned scope.

Inspect current state before editing.

Use only relevant skills/tools.

Avoid repeating repository scans, documentation lookups, or external calls already completed by another worker.

Fix root causes.

Validate the result.

Preserve unrelated work.

Report changed files, validation, risks, and commit state.
